# ZenMind — The Digital Sanctuary

A mental wellness web application that blends ancient wisdom with modern technology.

## Features

- **Guided Meditation** — Timer-based sessions with breathing exercises and stretching
- **Community Support** — Anonymous peer support groups with posts, comments, and likes
- **Professional Care** — Therapist directory with booking capabilities
- **Zena AI** — AI-powered wellness companion
- **Talk** — Connect with live listeners for real-time support

## Tech Stack

- **React 19** with Vite
- **Framer Motion** for animations
- **Supabase** for auth, database, and real-time features
- **CSS Modules** for scoped styling
- **Lucide React** for icons

## Getting Started

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

## Environment Variables

Create a `.env` file with your Supabase credentials:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
